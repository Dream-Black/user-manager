## 2. 产品定义

### 2.1 产品目标

**目标一：简化日常收支记录**
通过简单模式和清单模式两种入口，让用户能够快速记录每一笔支出；通过AI自动分类减少手动分类负担，提升记录效率。

**目标二：多账户资金可视化**
支持多账户管理（现金/银行卡/支付宝/微信等），自动追踪各账户余额变化，提供直观的时间范围存款曲线图，帮助用户清晰掌握财务状况。

**目标三：工资收入结构化管理**
通过工资明细模板规范每月工资录入，支持自定义子项结构，区分"实际到手收入"，为后续财务分析提供结构化数据基础。

### 2.2 用户故事

| # | 用户故事 |
|---|----------|
| US-01 | 作为用户，我希望快速记录一笔零散支出（金额+用途），系统能自动在23:59按AI分类，无需手动选择分类 |
| US-02 | 作为用户，我希望按清单模式记录一笔聚餐账单，系统能自动汇总各项金额，减轻心算负担 |
| US-03 | 作为用户，我希望查看某商品的历史购买价格趋势，帮助判断当前价格是否划算 |
| US-04 | 作为用户，我希望管理多个支付账户，并在消费时自动从默认账户扣款，同时支持账户间转账 |
| US-05 | 作为用户，我希望查看任意时间段的支出分类饼图，并点击某个分类下钻查看明细流水 |
